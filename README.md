# Сънят на новороденото 3.0
A static Bulgarian course library: six modules, 27 lessons, 26 videos and five unique attachments. Redistribution permission was confirmed by the site owner.

Serve this directory over HTTP; the app loads `course.json`. The lesson sidebar, overview and player are in `app.js`, presentation in `styles.css`, and route helpers in `navigation.mjs`. All asset paths are relative so the site works beneath a GitHub Pages repository path. Update `course.json` to maintain lesson content. Original video downloads are kept separately; published videos are compressed copies.

External YouTube videos, websites and Google Sheets templates remain links. No visitor accounts, analytics or cookies are required.

Live site: https://desi109.github.io/newborn-sleep-course/
